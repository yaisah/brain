# Brain — Claude Code entrypoint

This top-level folder is the brain; live `Projects/` and shared knowledge paths are here.
Read `docs/OPERATING_GUIDE.md` before private content. For "help me get started" or workspace
creation, follow `docs/GETTING_STARTED.md`; opening a folder alone starts no workflow.

Choose scope from the request: resolve one workspace for focused work; use the
brain registry for explicitly brain-wide planning, review, or configured intake.
A saved recurring scope does not require selecting every workspace again. Toolkit
maintenance needs no private workspace. Use this toolkit's canonical local skills and
only the context relevant to the authorized scope.

For app development, follow `docs/APPLICATIONS.md` and the selected repository's
instructions. Folder organization does not grant host filesystem/network permissions.

For delegated work or resuming a longer assignment, read `docs/COORDINATION.md`
for task ownership, separate worker outputs, and evidence-based handoffs.
